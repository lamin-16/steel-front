# City Runner

Танковая игра для браузера. Без установки, без регистрации, без рекламы — открыл и играешь.

Я сделал её, потому что хотел танковую игру, которую можно запустить на телефоне в перерыве, не дожидаясь загрузки. Оказалось, что ещё нескольким людям это нужно.

## Как это устроено

Здесь два слоя.

Первый — быстрый танковый бой. Ты едешь, целишься, стреляешь — пробиваешься через волны вражеской брони по открытой местности, через города и леса. Тип снаряда важен. Угол тоже. Один точный APCR в борт «Пантеры» ощущается совсем иначе, чем очередь HE по лбу.

Второй слой — военная карта. Ты начинаешь с тремя секторами на европейском фронте. Каждый сектор что-то производит: топливо, боеприпасы или промышленность. На это ты покупаешь рекрутов, улучшения, форты и, в конце концов, ядерные боеголовки. Потом размещаешь части на соседних секторах и позволяешь бою разрешиться в поле.

Потеряешь сектор — враг продавит дальше. Возьмёшь — фронт расширится. Карта — не декорация. Это вся кампания.

## Что нужно

Node.js 18 или новее.

    npm install
    npm start

Открыть http://localhost:3000.

## Управление

- Левый стик — движение
- Правый стик — поворот башни
- ОГОНЬ — выстрел
- AP / APCR / HEAT / HE — смена снаряда
- Ряд способностей — артиллерия, ремонт, дым, авиаудар, огнетушитель

## Сложность

- ЛЁГКАЯ — четыре стартовых сектора, врагов меньше. Подходит для знакомства.
- НОРМАЛЬНАЯ — три сектора. Задуманный вариант.
- ТЯЖЁЛАЯ — один сектор, врагов больше, без поблажек.

После капитуляции или нового старта есть 90 секунд, пока враг не двигается. Потрать их на план.

## Что есть в игре

- Пять континентов со своим множителем врагов и ценой открытия
- Экстренная помощь — раз в час сбрасывают ресурсы, если дела плохи
- Ядерные удары — 300 промышленности, 150 топлива, 150 боеприпасов, около трёх минут производства
- Линии снабжения через форты (60 промышленности, 40 боеприпасов за форт)
- Ежедневная награда с отмеченным сектором на 200 промышленности
- Четыре типа командиров — Iron Fist, Thunder, Hammer, Storm
- P2P-мультиплеер через WebRTC (ранний, ещё сырой)

## Технологии

- Three.js для рендеринга
- Express для тонкого бэкенда
- @noble/post-quantum для подписанных записей в таблице лидеров (ML-KEM-768, ML-DSA-65)
- PeerJS для мультиплеера

## Языки

Английский, немецкий, русский, арабский. Переключатель языка в игре — вверху экрана.

## Замечание о коде

Военный модуль (war-module.js) загружается после основной игры и внедряет свой интерфейс. Своё состояние он хранит в localStorage под ключом steel_front_war_v2. Чтобы сбросить карту, используй кнопку SURRENDER — она очищает секторы, части и форты, но сохраняет ресурсы: они задуманы как постоянные между континентами.
